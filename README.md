# Website Berita

Kumpulan template website portal berita modern & dinamis.

## Daftar Template

### 1. `template_1` - NusaKabar
Portal berita berbasis Next.js App Router, TypeScript, Tailwind CSS, PostgreSQL/Prisma, dan Auth.js.

- **Fitur Utama:**
  - Halaman publik (Berita Terbaru, Populer, Kategori, Detail Artikel)
  - Dashboard Redaksi & Manajemen Konten (CMS)
  - Autentikasi Pengguna & Role Redaksi
  - Desain responsif & modern

- **Cara Menjalankan:**
  Masuk ke direktori `template_1` dan ikuti petunjuk pada [README template_1](./template_1/README.md).

```bash
cd template_1
npm install
npm run dev
```
